# 中繼站安裝說明（Cloudflare Workers・免費）

## 這是在解決什麼

在職訓練網把 GitHub 主機所在的機房 IP 整段封鎖了，一律回應 504。
但同樣在國外的其他主機卻連得到——所以只要換一段沒被封的 IP 代抓一次就好。

裝好之後：**課程資料完全自動更新，公司電腦、家裡電腦、手機都不用裝任何東西。**

免費額度是每天 10 萬次請求，我們每個月大概用 30 次。**不用信用卡。**

---

## 步驟

### 1. 註冊 Cloudflare 免費帳號

打開 https://dash.cloudflare.com/sign-up

用 email 或 Google 帳號註冊都可以。**過程中不會要信用卡**，若看到要付費的畫面代表點錯地方了，退回重來。

### 2. 建立一個 Worker

登入後在左邊選單找 **Workers** 或 **Compute**（Cloudflare 偶爾改介面，名字大意是「Workers」就對了），
按 **Create application** → **Create Worker**。

名稱隨便打，例如 `course-relay`，然後按 **Deploy**（先部署一個空殼，等一下再換內容）。

### 3. 貼上程式碼

部署完會出現 **Edit code** 或 **編輯程式碼** 的按鈕，點進去。

把編輯器裡**原本的內容全部刪掉**，換成 `cloudflare-worker.js` 這個檔案的完整內容
（在同一個資料夾裡，用記事本打開，全選複製）。

貼好後按 **Deploy** / **Save and deploy**。

### 4. 測試通不通

部署完會給你一個網址，長得像：

```
https://course-relay.你的帳號.workers.dev
```

在網址**後面加上 `/?test=1`**，用瀏覽器打開，例如：

```
https://course-relay.你的帳號.workers.dev/?test=1
```

會看到中文結果：

- **「✅ 通了！」** → 把畫面上那行網址整段複製，貼給 Claude，剩下的我來設定
- **「❌ 沒通」** → 把整頁截圖給 Claude 看，這條路走不通，改用家裡電腦那顆按鈕

### 5. 交給 Claude

我會把網址存進 GitHub 的密鑰設定（不會公開），之後每月自動更新就會走這條路。
