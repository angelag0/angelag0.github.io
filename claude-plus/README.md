# Claude Plus

讓 VS Code 的 **Claude Code** 擴充更好用的小外掛，兩組功能合在一個擴充裡：

| 功能 | 說明 |
|---|---|
| 🧠 **思考中譯** | 思考區塊預設展開；每則思考旁一顆「譯」按鈕，點一下英文變繁中、再點換回原文 |
| ♻️ **復原對話** | 官方面板的垃圾桶其實**只是隱藏、不會刪檔**。這顆按鈕把被隱藏的對話放回清單（誤刪救星） |
| 🧹 **清理對話** | 把隱藏中的對話**真的刪除**：對話檔連同附屬資料一起**移到資源回收筒**（可反悔） |
| 🎲 **重骰自動收尾** | 在面板用 Rewind 重骰後，被分岔掉的舊對話**自動隱藏**，清單不再堆滿分身 |

「♻️ 復原對話」「🧹 清理對話」是 VS Code 右下角**狀態列**的兩顆按鈕，點了就能用，全程不需要終端機。

---

## 安裝

1. 下載本資料夾的 `claude-plus-2.0.0.vsix`
2. VS Code 左側「擴充功能」→ 右上角 `...` → **Install from VSIX...** → 選它
3. 依提示**重新載入視窗**（很重要，見下方原理）

換電腦時把同一個 `.vsix` 帶著裝就好。

### 加碼：開啟思考摘要（建議，30 秒）

Claude Code 預設不顯示思考內容，思考區塊會是空的。在本資料夾開 PowerShell 執行：

```powershell
powershell -ExecutionPolicy Bypass -File .\apply-setting.ps1
```

它會在 `%USERPROFILE%\.claude\settings.json` 加入 `"showThinkingSummaries": true`（執行前自動備份、
可重複執行）。**開一個新的 Claude Code 工作階段才生效**。這不會多花錢——思考本來就在發生、
本來就計費，這只是把文字顯示出來。

---

## 快速上手：重骰（Reroll）

對 Claude 的回覆不滿意時：

1. 滑鼠移到**你上一則訊息**上 → 點 **Rewind** → **Continue**
2. 重新送出（可以原句重問，也可以改幾個字）→ 得到新的回覆
3. 舊的那條分身會**自動從清單消失**——不用再手動按垃圾桶
4. 想大掃除時按右下角 **🧹 清理對話**：勾選 → 確認 → 移到資源回收筒
5. 刪錯了？按 **♻️ 復原對話** 隨時救回（只要還沒被 🧹 清掉）

> 背景知識：Claude Code 的 Rewind 是 "Fork and rewind"——每重骰一次就複製出一個新對話檔，
> 舊檔原封保留。這就是清單容易堆滿相同開頭分身的原因。本擴充把「隱藏舊分身」自動化，
> 再配一顆「真刪除」按鈕收尾。

## 指令（命令面板 `Ctrl+Shift+P`）

- `Claude Plus: 套用修補`
- `Claude Plus: 還原 Claude Code 原始檔` — 從備份還原，等於完全卸除修改
- `Claude Plus: 檢查狀態` — 顯示各項修補是否生效
- `Claude Plus: ♻️ 復原已刪除的對話` — 同狀態列按鈕
- `Claude Plus: 🧹 清理對話（真刪除，丟資源回收筒）` — 同狀態列按鈕

## 設定

| 設定 | 預設 | 說明 |
|---|---|---|
| `claudeThinkingZh.autoExpand` | `true` | 思考區塊預設展開 |
| `claudeThinkingZh.targetLang` | `zh-TW` | 翻譯目標語言（`zh-CN`、`ja` 等亦可） |
| `claudeThinkingZh.autoPatchOnStartup` | `true` | 啟動時自動檢查並重補 |
| `claudeThinkingZh.autoHideOnRewind` | `true` | 重骰後自動隱藏被分岔掉的舊對話 |

（設定鍵沿用 1.x 的 `claudeThinkingZh` 前綴，升級不會遺失既有設定。）

## 運作原理

VS Code 不允許一個擴充操作另一個擴充的介面與資料，所以 Claude Plus 是**直接修改
Claude Code 擴充的檔案**（改之前都留 `.ctzh-orig` 備份）：

| 目標檔案 | 修改內容 |
|---|---|
| `webview/index.js` | 檔尾附加腳本：思考自動展開＋翻譯按鈕（標記 `__CLAUDE_THINKING_ZH__`） |
| `extension.js` | ① CSP 補上 `connect-src https://translate.googleapis.com`（翻譯連線）；② 檔尾附加對話管理程式（標記 `__CTZH_SESSIONS__`）：在官方擴充自己的行程內註冊「復原／清理」指令，用官方的儲存介面合法讀寫隱藏黑名單；③ 精準替換 fork 處理程式，加上重骰自動隱藏（標記 `__CTZH_AUTOHIDE__`；版本對不上就整項跳過，不影響其他功能） |

**關於垃圾桶按鈕的真相**：官方面板的刪除鈕只是把對話 id 加進一個「隱藏黑名單」
（存在 VS Code 的內部設定庫），對話檔 `.jsonl` 一直都躺在
`~/.claude/projects/<專案資料夾>/` 裡。所以：誤刪可救（♻️ 從黑名單移除）、
想真刪得另外動手（🧹 把檔案移到資源回收筒並同步清黑名單）。

**自動重補**：Claude Code 每次更新都會裝到新資料夾，修改隨之消失。本擴充每次
VS Code 啟動時自動檢查，發現沒補就重補並提示重新載入。

**開機自動復原**：啟動時若發現 `~/.claude/ctzh-pending-unhide.json`（要復原的對話 id
清單），會自動把它們從黑名單移除——給外部工具或救援腳本排隊用。

### 為什麼補完一定要重新載入視窗

`extension.js` 是 VS Code **啟動時就整個讀進記憶體**的，補丁寫入的時間點必然在那之後，
所以「剛補上的那一次開機」對目前視窗必定無效。偵測到這種情況會跳強制對話框要求重新載入；
不重載的話翻譯按鈕會顯示 `⚠`、對話管理按鈕會提示尚未生效。

## 解除安裝（順序很重要）

**先執行「還原」指令，再解除安裝擴充：**

1. `Ctrl+Shift+P` → `Claude Plus: 還原 Claude Code 原始檔`
2. 依提示重新載入視窗
3. 再到擴充功能面板解除安裝

順序反了也不是絕路——重新安裝本擴充跑一次「還原」，或直接重新安裝 Claude Code 擴充即可。

## 疑難排解

| 症狀 | 原因與處理 |
|---|---|
| 翻譯按鈕顯示 `⚠` | CSP 還沒生效。重新載入視窗。 |
| 翻譯按鈕顯示 `✕`＋HTTP 429 | Google 免費端點限流，等幾分鐘再試。 |
| 完全沒有翻譯按鈕 | 跑 `Claude Plus: 檢查狀態` 看各項修補。 |
| 按 ♻️/🧹 跳「需要重新載入」 | 補丁剛套用、視窗還沒載入它，照提示重載一次。 |
| ♻️ 復原後清單沒出現 | 清單要重新整理：關掉側欄再開，或重開面板。 |
| 想看詳細錯誤 | `Ctrl+Shift+P` → `Developer: Open Webview Developer Tools`，Console 搜 `claude`。 |

## 注意事項

- **翻譯會把該則思考的文字送到 Google 伺服器**（免費公開端點，非官方 API）。只有你按下
  按鈕的那一則會送出。**對話管理功能完全不連網。**
- 🧹 清理一律先列清單勾選＋跳確認框，且是移到**資源回收筒**而非永久刪除。
- 這是在修改 Anthropic 的擴充檔案，不受官方支援；隨時可用「還原」指令完全復原。
- Claude Code 大改版導致修補失敗時，本擴充會整個略過、不留半套修補，不會把面板弄壞。

## 從原始碼打包

改了 `src/` 之後執行（不需要 node/npm）：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```
